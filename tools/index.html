The Premise

Some questions should not take an afternoon. What has been permitted at this address? Which parcel is it, and whose jurisdiction? Does this story still hold together? Each of these is a small, answerable thing — so I built a small, answerable tool for it, and left the door open.

They are read-only, ask for no account, and speak the same language an AI assistant does, so you can use them yourself or hand them to the agent you already work with. The code is public under the MIT licence; the data comes from the public record and says where it came from.

A Note

The permit tool reaches the county's and twenty cities' own systems as you ask; where a city offers no public search, it falls back to the Assessor's record and tells you so. Nothing here is legal advice, and a permit's status is always the issuing jurisdiction's to confirm.
